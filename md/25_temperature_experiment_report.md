# LLM의 Temperature 에 따라 추출하는 성분이 다른지 궁금해서 질문해봄

# 온도(Temperature) 변화에 따른 추천 성분 실험 리포트

사용자의 "머리 아파" 질문에 대해 타이레놀(아세트아미노펜) 누락 여부와 온도별 추천 성분의 변화를 실험한 결과입니다.

## 1. 실험 환경
- **질문**: "머리 아파"
- **추출된 키워드**: `HEADACHE`
- **FDA 검색 원본 데이터 (상위 10개)**:
  1. ACETAMINOPHEN (아세트아미노펜)
  2. DEXTROMETHORPHAN HYDROBROMIDE
  3. GUAIFENESIN
  4. ASPIRIN
  5. IBUPROFEN
  6. NAPROXEN SODIUM
  ... (총 20개 성분 추출)

## 2. 온도(Temperature)별 추천 결과 요약

| 온도 (Temp) | 추천된 주요 성분 리스트 | 요약 및 특징 |
| :--- | :--- | :--- |
| **0.0** | ACETAMINOPHEN, ASPIRIN, CAFFEINE | 가장 표준적이고 보수적인 추천. 불필요한 성분을 배제하고 핵심 진통제 위주로 구성됨. |
| **0.5** | ACETAMINOPHEN, ASPIRIN, CAFFEINE | 0.0과 거의 동일한 성분이 추출되나, 답변의 문장 표현이 서술형으로 조금 더 부드러워짐. |
| **1.0** | ACETAMINOPHEN, ASPIRIN, CAFFEINE, (가끔 IBUPROFEN 추가) | 답변의 문장이 다채로워지며, 드물게 순위권 밖의 진통 성분이 하나 더 추가되기도 함. |

## 3. 타이레놀(아세트아미노펜) 누락 원인 분석 결과

실험 결과, **로직상으로는 타이레놀이 항상 1순위로 나오고 있습니다.** 하지만 실제 사용 시 누락된 원인은 다음 중 하나일 확률이 높습니다:

1. **사용자 건강 프로필의 영향**: 사용자가 입력한 프로필(복용 중인 약, 알레르기 등)에 '타이레놀'이나 '아세트아미노펜'과 중복되거나 충돌하는 성분이 있을 경우, AI가 안전을 위해 이를 리스트에서 제외하거나 `can_take: false`로 처리하여 뒤로 보낼 수 있습니다.
2. **성분 리스트의 한계**: FDA 검색 결과가 너무 많을 경우(20개 이상), AI가 텍스트 길이를 조절하기 위해 임의로 몇 가지만 골라 요약하는 과정에서 뒤로 밀렸을 가능성이 있습니다.
3. **캐시 데이터**: 이전에 잘못 분석된 결과가 `cache_key`에 의해 저장되어 있었다면, 로직을 수정해도 한동안 잘못된 답변이 보였을 수 있습니다.

## 4. 결론 및 조치 계획
- **온도 0 고정**: 실험 결과 온도 0에서 가장 정확하고 일관된 진통제 리스트가 제공됨을 확인했습니다.
- **가중치 로직 보강**: "머리 아파"와 같은 대표 증상에는 `ACETAMINOPHEN`과 같은 필수 성분이 **반드시 상단에 고정**되도록 검색 순위 가중치 로직을 이미 적용 완료했습니다.
- **캐시 초기화**: 수정된 로직이 즉시 반영되도록 캐시 초기화를 권장합니다.
